# Custom Pages

Create standalone pages at `/page/{slug}` from **Admin → Custom Pages**.
Pages are drafts until published. Published pages are included in TinyCat's
sitemap; their URL slug then stays fixed to preserve incoming links.

Content uses safe, intentionally limited HTML. The editor provides shortcuts for
headings, paragraphs, lists, emphasis, links, quotes and code; raw HTML is
sanitized before it is stored and rendered.
